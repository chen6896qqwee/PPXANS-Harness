# 文献综述

## 适用
需要把 ≥ 5 篇文献/资料整理成有结构、有对比、有缺口的综述 (而非逐篇摘要的堆砌)。

## 流程

1. **先写检索策略**: 检索词 (含同义词与英文对应)、来源库、时间范围、语言限制。策略要能被别人复现 —— 不可复现的综述等于读后感。
2. **定纳入/排除标准, 并在检索后先筛再读**。标准写在前: 主题相关性、方法类型、质量门槛、时间窗。排除的原因要记录 (排除清单本身是信息)。
3. **逐篇提取固定字段** (统一表格, 避免每篇写法不同): 作者/年份 / 研究问题 / 方法 / 样本或数据 / 主要结论 / 局限 (作者自述) / 与你综述问题的关系。
4. **主题聚类而非时间排序**: 按研究视角或方法分组。同一主题下把结论一致与冲突的分开摆。
5. **方法对比表**: 不同方法的样本、控制条件、评价指标并列 —— 多数"结论冲突"其实是方法差异造成的。
6. **指认研究缺口**: 哪些问题没人研究、哪些结论只有单一样本支持、哪些方法有系统性局限。缺口必须由前文的对比推出来, 不能凭空提。
7. **引用纪律**: 每条引用标到具体文献; 转述二手引用时标注"转引自"。**没读原文的不许写进综述**, 只读过摘要的要标"仅据摘要"。
8. **输出**: 检索策略 → 纳入/排除及数量 → 主题聚类综述 → 方法对比表 → 结论一致与冲突 → 研究缺口 → 参考文献。

## 反合理化
- "先读完所有文献再组织" → 读完就忘。用固定字段表边读边提, 最后聚类。
- "这几篇结论差不多, 合成一段" → 先看样本与方法。差异常藏在限定条件里。
- "摘要里写了结论, 直接用" → 摘要的结论常省略限定条件, 是误引的主要来源。标"仅据摘要"。
- "缺口随便提一个显得有洞见" → 缺口必须从对比中长出来, 否则是臆想。
- "参考文献按出现顺序列就行" → 引用格式要统一, 缺卷号页码的条目说明你没核对过。

## 验证
- [ ] 检索策略可复现 (含同义词与库)
- [ ] 纳入/排除标准前置, 排除数量已记录
- [ ] 每篇有统一字段的提取表
- [ ] 按主题聚类, 一致与冲突分开陈列
- [ ] 有方法对比表
- [ ] 研究缺口由对比推出
- [ ] 无未读原文的引用; 仅据摘要者已标注
