# 会话命名模板（Session Naming Kit）

## 流程

1. **取信号**：只看首轮对话里"用户想干什么"这件事——不要用问候语、不要用助手回复的开场白。
2. **压到 4–12 字**：中文按字算，英文按词算。超出就砍修饰语，保动作与对象。
3. **去泛词**：`帮我` / `请` / `一下` / `关于` / `问题` 一律删掉——它们不提供区分度。
4. **保专名**：项目名、文件名、技术栈、版本号属于高价值信号，优先保留。
5. **同名去重**：与已有会话标题重复时，追加可区分后缀（日期 / 序号 / 具体对象）。

## Few-shot 示例

| 首轮对话（节选） | 坏命名 | 好命名 |
|---|---|---|
| "你好，帮我看看这个 PPXANS-Harness 项目为什么跑不起来" | 新对话 | PPX 内核启动失败排查 |
| "我想优化一下记忆检索的排序算法" | 讨论 | L1 记忆 BM25 排序优化 |
| "把这个 md 拆成按主题的小文件" | 文件处理 | 提示词合集按主题拆分 |
| "现在几点了" | 时间查询 | —（寒暄/单轮，不起名） |
| "继续" | 继续 | —（无信息量，沿用上轮标题） |

> 判据：**如果这个标题不能让你在两周后一眼认出是哪次对话，就重写。**

## 反合理化

- "用第一句话原文当标题"——原文包含问候与口语，区分度低。
- "给寒暄也起个名"——"你好"起的任何名字都是噪音。
- "标题越长越准确"——列表里只显示十几个字，长的会被截断，等于没写。

## 验证

必须给出：① 生成标题；② 字数与去词记录；③ 与已有会话标题的重名检查结果。
