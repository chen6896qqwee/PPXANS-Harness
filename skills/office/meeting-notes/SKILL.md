# 会议纪要

## 适用
已有会议素材 (转写文本、笔记、聊天记录、录屏字幕), 需要产出纪要与待办。

## 流程

1. **先分四类, 再动笔**: 把原始素材的每句话归入 —— 决议 (已定)、待办 (要做)、讨论 (未定)、信息 (背景)。归不了类的先放着, 不要硬塞。
2. **决议只记已达成的**: 格式「决议: xxx | 提出人 | 依据」。讨论中没人反对 ≠ 达成决议, 除非明确说"就这么定"。
3. **待办必须四要素齐全**: 做什么 / 谁 / 什么时候 / 验收标准。缺责任人 → 标「待指派」; 缺时间 → 标「未定」并列入待确认。四要素不全的待办等于没有待办。
4. **讨论分歧单独成节**: 写清各方观点与未解决的原因, 并写明"由谁在什么时候定"。
5. **不确定的转写要标注**。录音转写常有错字, 涉及人名/数字/金额时标注"[转写待确认]", 不要自行纠正为看起来合理的值。
6. **原文摘要只保留决策相关信息**: 寒暄、重复、跑题内容一律不进纪要。
7. **输出结构**: 会议信息 (时间/参与人/主题) → 决议 → 待办清单 (表格式: 事项/责任人/截止/验收) → 未决分歧 → 待确认项。
8. **分发前核对**: 参与人姓名、金额、日期三类信息逐条对照原文。

## 反合理化
- "大家都点头了就算定了" → 记录里没有明确结论的, 一律进讨论节。
- "责任人回头再补" → 没有责任人的待办会在下次会议上重新出现。当场标「待指派」也比空着强。
- "转写有点乱, 我理顺一下" → 理顺措辞可以, 但涉及事实的模糊处必须保留不确定标记。
- "纪要约详细越好" → 纪要的价值在决议与待办, 详细讨论会让关键信息被淹没。

## 验证
- [ ] 素材已按决议/待办/讨论/信息四类归置
- [ ] 每条待办四要素齐全 (缺项已显式标注)
- [ ] 未决分歧单列, 且有裁决人/时间
- [ ] 转写不确定处已标注
- [ ] 人名/金额/日期已逐条核对
