# 中文文案

## 适用
面向真实读者的对外传播文本: 公众号、社交平台、产品介绍、活动宣传、邮件开场。
不适用: 正式公文 (用 docx-report)、技术文档 (用 docs 类流程)。

## 流程

1. **先定"读者读完要做什么"**。是点进链接、记住一个观点、还是转发? 目标不同, 结构完全不同。写不出单一目标就先问。
2. **标题先写 5 个再挑 1 个**。好标题来自对比, 不来自一次灵感。挑的时候写清"为什么这个比另外 4 个强"。
3. **结构: 钩子 → 冲突 → 兑现 → 行动**。
   - 钩子: 具体场景或反常识事实 (不要"在当今时代")
   - 冲突: 读者的痛点或认知落差
   - 兑现: 正文必须真的给出钩子承诺的东西 (标题党 = 一次性流量)
   - 行动: 一个具体、低门槛的动作
4. **去 AI 味** (逐条自查, 可直接调 humanize 工具):
   - 删掉排比堆砌 ("不仅仅是…更是…")
   - 删掉模糊归因 ("业内认为/数据显示" 无出处)
   - 删掉连接词连用 ("首先…其次…总之…")
   - 删掉空收尾 ("未来可期/值得期待")
   - 破折号与冒号各不超过 2 处
   - 每段不超过 4 行, 长句拆短
5. **具体压倒抽象**: "效率提升 3 倍" 好过 "大幅提升"; 举一个真实例子好过举三个泛指例子。
6. **立场要清楚**。文案没有观点的原因是作者没想清楚, 不是因为中立。给出明确态度, 但不要攻击特定个人。
7. **交付含 3 个备选标题** + 正文 + 建议配图方向。

## 反合理化
- "先把内容写出来, 标题回头想" → 标题就是内容的角度。先写会写出一篇没有角度的稿子。
- "读者喜欢看排比" → 读者喜欢节奏, 不喜欢空转。排比若无信息增量就是噪音。
- "加点数据显得专业" → 没出处的数据是负资产。宁可没有。
- "AI 味调一下就行" → 去 AI 味不是换词, 是删掉没有信息量的句子。词换了句子还在, 味还在。

## 验证
- [ ] 读者与目标动作明确
- [ ] 5 个备选标题 + 选择理由
- [ ] 四段结构完整, 钩子与正文兑现一致
- [ ] 逐条过了去 AI 味自查
- [ ] 至少 2 处具体数字或实例
- [ ] 立场明确, 无空收尾
