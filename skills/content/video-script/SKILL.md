# 视频脚本

## 适用
需要产出可直接拍摄/生成的视频脚本 (短视频、口播、漫剧分集、产品演示)。
不适用: 长文写作 (用 copywriting-zh)、纯分镜运镜设计 (用 manju 系列能力)。

## 流程

1. **先定三件事**: 总时长、平台 (竖屏/横屏、完播率机制)、单条核心信息。三者任一未定, 脚本必然返工。
2. **按秒拆结构** (以 60 秒为例): 0-3 秒钩子 / 3-15 秒冲突 / 15-50 秒推进 / 50-60 秒收束与行动。时长不同按比例缩放, 但**钩子必须在前 3 秒**。
3. **逐镜写五行**: 镜号 / 时长 / 画面 (可见的具体动作与景别) / 台词或字幕 / 音效或音乐。五行缺一镜都不完整。
4. **画面必须可执行**: 写"她盯着屏幕, 手指停在回车键上"而不是"表现她的犹豫"。生成式视频尤其如此 —— 抽象形容没法变成提示词。
5. **台词按口语写**: 写完出声读一遍, 读着别扭就改。书面语进不了口播。
6. **每 15 秒一个信息点或情绪转折**, 否则完播率会掉。转折点标注出来。
7. **配套产出**: 分镜表 + 角色/场景一致性要点 (供图像生成复用) + 每个镜头的视频提示词要点 (主体/动作/景别/机位/光线)。

## 反合理化
- "先写台词再配画面" → 台词会写出无法呈现的内容。画面与台词同步设计。
- "时长无所谓, 剪的时候再说" → 时长约束是脚本存在的意义。没有时长约束写出来的是短文不是脚本。
- "画面描述写得美一点更有感觉" → 美感留给视觉设计。脚本的画面描述要能被执行。
- "钩子可以放到第 10 秒" → 竖屏前 3 秒决定生死, 第 10 秒已经流失一半观众。

## 验证
- [ ] 总时长/平台/核心信息已明确
- [ ] 钩子在前 3 秒
- [ ] 每个镜头五行齐全
- [ ] 画面描述具体可执行 (无抽象形容词)
- [ ] 台词朗读过一遍
- [ ] 每 15 秒有信息点或转折, 已标注
- [ ] 附了一致性要点与视频提示词要点
