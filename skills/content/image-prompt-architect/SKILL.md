# 图像提示词构建

## 适用
需要用文生图或图生图产出视觉内容, 但需求描述还很模糊 ("来一张科幻感的")。
不适用: 已经明确知道要哪个模型的具体语法 (直接写即可)。

## 流程

1. **先问四件事** (缺一项就别开始): 用途 (封面/插图/角色设定/场景概念)、画面尺寸与版式 (竖/横/方)、主体是谁或什么、必须出现与必须不出现的元素。
2. **六段式组装** (顺序即权重, 越前越重要):
   1. 主体: 谁/什么 + 具体状态 (年龄/服饰/动作/表情)
   2. 环境: 地点 + 时间 + 天气 + 背景元素
   3. 构图: 景别 (特写/中景/全景) + 视角 (平视/俯视/仰视) + 主体位置 + 留白
   4. 镜头与光线: 焦段感 (广角/长焦) + 光位 (逆光/侧光/顶光) + 明暗对比
   5. 风格与材质: 画风 + 媒介 (电影感/胶片/3D 渲染/水墨) + 质感关键词
   6. 技术约束: 尺寸、比例、不要出现的元素 (负面约束)
3. **一致性锚点**: 需要多张图 (同一角色/同一场景) 时, 把不变量单独抽成一段固定前缀 (外貌、服饰、色调), 每次复用; 只改场景与动作部分。这是系列图不崩的关键。
4. **具体压倒抽象**: 颜色写色名或色值、光线写方向与软硬、风格写参考媒介而不是形容词。"唯美" 这种词对模型无信息量。
5. **负面约束显式写**: 多手多指、文字水印、透视错误、比例失调 —— 按模型常见失败模式列。
6. **给 2~3 个变体并说明区别** (只改一个维度), 便于用户对比选择, 而不是给一堆随机风格。
7. **交付**: 提示词正文 (可直接复制) + 一致性前缀 (如有) + 负面约束 + 每个变体改了什么。

## 反合理化
- "描述得越华丽效果越好" → 模型吃的是具体名词与方向, 不是形容词密度。
- "一张不行多抽几次" → 抽卡是补偿提示词模糊的成本。先把六段补齐, 命中率立刻上升。
- "风格词堆多了总有一个中" → 风格词互相冲突 (水墨 + 赛博朋克) 会让画面崩解, 不是叠加。
- "系列图每次都重写提示词" → 不抽一致性前缀, 第二张就不是同一个人了。

- [ ] 六段式齐全, 每段有具体描述词
- [ ] 系列图抽取了固定一致性前缀
- [ ] 负面约束按模型失败模式列出
- [ ] 多版本只改单一维度并说明差异
