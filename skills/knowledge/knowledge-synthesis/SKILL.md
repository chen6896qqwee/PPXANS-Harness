# 知识蒸馏

## 适用
输入 ≥ 2 份材料, 输出一份比输入短得多、但信息量不损失的结论文档。
不适用: 单份材料的摘要 (那是 summarization, 直接用 read_document + 一句指令即可)。

## 流程

1. **先清点, 再动手**。列出材料清单 (标题 + 来源 + 时间)。缺材料先说缺什么, 不要用推测补。
2. **逐份抽"原子主张"**: 一句话一个主张, 带上出处标记 (材料编号)。此时不做任何合并。
3. **合并同义**: 多个材料说同一件事 → 合并成一条, 出处标记累加。合并时取**信息量最大的表述**, 不要取最含糊的。
4. **标注冲突**: 同一条主张出现互斥版本 → 单独成条, 列出各自版本与出处, 写明"未调和"。禁止按"更权威/更顺眼"私自选边。
5. **分层**: 
   - 事实层: 有明确出处的陈述
   - 判断层: 材料的推论/评价 (标"某方观点")
   - 缺口层: 材料都没覆盖但问题需要的问题
6. **压掉重复的修辞**: 删除套话、背景铺垫、重复举例。保留数字、条件、例外、否定。
7. **输出**: 结论集 (编号 + 出处) → 冲突清单 → 缺口清单 → 出处索引。

## 反合理化
- "材料太长, 我概括一下大概意思" → 概括≠蒸馏。概括丢条件与例外, 蒸馏必须保住数字与否定。
- "两份材料说法差不多, 合成一条吧" → 先看差异在哪。很多时候差别正好在关键限定词上。
- "这个结论材料里没写, 但我推断是" → 推断要单独放缺口层, 不能混进结论集。
- "重复的内容删掉就行" → 重复但出处不同的内容, 出处本身是信息 (说明多方独立印证)。累加出处而不是直接删。

## 验证
- [ ] 材料清单完整, 缺失项已说明
- [ ] 每条结论带出处标记
- [ ] 冲突项单列且未被静默调和
- [ ] 数字/条件/否定在压缩后仍然保留
- [ ] 缺口清单非空 (或明确写"无缺口")
