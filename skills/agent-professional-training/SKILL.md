# Agent 专业训练规程（Universal Agent Training Playbook）

一套与具体框架无关的 Agent 能力训练与审计规程。审计时应把它当透镜逐个环节照，**先找最弱环，再从最弱环补**——不存在"全面加强"，只有"补上短板"。

## 流程

### 1. 核心公式与定位

```
Agent 能力 ≈ 想 × 记 × 做 × 学 × 评  （乘法，任一环为 0 则整体为 0）
```

乘法而非加法是关键：**评估能力缺失会让"学"失去方向，而"做"的工具杠杆不足会让"想"的价值无法落地**。审计时先定位那个接近 0 的因子。

### 2. 想：规划先行

- 复杂任务先出计划（2–6 步）再执行，计划要可验证、可回退。
- 计划执行中允许修正，但**修正必须有触发条件**（某步失败 / 信息更新），不是随意改。
- 多方案时保留备选，避免单路径死锁。

### 3. 记：四层记忆系统

| 层 | 内容 | 衰减 |
|---|---|---|
| L0 | 原始对话（append-only 事件日志） | 不衰减 |
| L1 | 原子事实（高斯衰减 + 命中加分） | 快 |
| L2 | 场景聚类 | 中 |
| L3 | 画像（用户 / Agent 人格） | 慢 |
| L4 | 程序性记忆（技能 / 流程） | 仅为 L1 的 1/4 |

**要点**：记什么比记多少重要。跨会话仍然成立的信息才入库；提问、寒暄、一次性中间结果不入库（否则记忆越用越脏，还会喂回上下文污染后续判断）。

### 4. 做：工具杠杆

- **参数要校验**：声明了 schema 就必须在运行时校验。参数错的代价是浪费一整轮 LLM 交互。
- **副作用要分级**：幂等工具可重试，非幂等工具**禁止自动重试**。
- **失败要可归因**：工具返回的错误必须能指向具体原因（参数 / 权限 / 超时 / 网络），不能统一吐"失败了"。

### 5. 学：失败 → 经验闭环

- 失败轨迹（≥2 条同类）→ 提炼一条可复用经验 → 存入经验库 → 后续任务自动注入。
- 成功轨迹（≥3 条且高频工具重复出现）→ 提炼技能 → **过闸门**（结构完整 + 引用真实工具 + 有轨迹背书）→ 才允许落盘。
- 闸门是必须的：没有闸门的自学习会往库里灌幻觉。

### 6. 评：评估与基线

- 没有基线就没有"变好了"这个判断。每次改进前后必须跑同一套任务集。
- 指标要含**单位成本**（通过任务数 / 十万 token），否则"提升"可能只是烧了更多 token。
- 失败要落库，接通"评估失败 → 反思原因 → 写入记忆"的循环。

### 7. 多智能体与仲裁

- 并行派发要有**有界并发**，不能一次性 spawn 海量子进程。
- 多路产出分歧时要有仲裁（共识聚类 / 评审循环），不能默认取第一个。
- 只读审查者要**真禁掉写操作**，不能只靠提示词约束。

### 8. 安全边界

- **deny-wins**：任一策略拒绝即拒绝，不可被低优先级 allow 覆盖。
- 策略订阅者异常要 fail-open（不拖垮执行）**但要有熔断兜底**（否则故障订阅者被反复触发）。
- 危险操作分三档：黑名单硬拦 / 高风险需审批 / 白名单放行。审批必须能"一次性授权"而非永久放行。

## 反合理化

- "全面加强一下"——乘法结构下，全面加强不如补最弱环。
- "先堆能力，评估以后再说"——没有评估，"学"就没有方向，堆的能力无法验证。
- "记忆越多越聪明"——脏记忆会污染判断，宁缺毋滥。
- "自动化重试更省事"——对非幂等操作重试是制造重复副作用。
- "提示词里写清楚别乱来就行"——安全边界必须是代码级不变量，不是提示词里的请求。

## 验证

### 9. 评估指标与回归（每次改进/训练后的必测项）

| 指标 | 采集方式 | 门槛 |
|---|---|---|
| 任务通过率 | 跑固定任务集 | 不低于基线 |
| 单位成本 | 通过任务数 / 10 万 token | 不劣于基线 |
| 工具失败率 | 按工具分组统计 | 单工具 > 30% 即需排查 |
| 回归测试 | 全量测试 | **0 失败**，非"减少失败" |
| 自愈基准 | 注入破坏后修复率 | 100% |

### 10. 落地路线图（先窄后宽）

1. **先窄**：选一个具体场景（如"读文件并总结"），把五环全跑通一遍，包括评估与回归。
2. **再宽**：场景验证通过后，才横向扩到新工具 / 新记忆层 / 新渠道。
3. **禁区**：不要在评估体系建成之前扩场景——那只是在累积未经检验的行为。

**交付要求**：每轮训练必须产出 ① 最弱环判定；② 补强动作；③ 前后对比数据；④ 回归测试新增项。
