# 回答表达深度提示词方案库（Prompt Depth Kit）

面对"回答太浅/太啰嗦/不切重点"三类问题时，按目标选一套方案注入提示词。

## 流程

1. **判型**：先分清问题出在哪 —— 信息不足（浅）、重点不明（散）、还是话太多（冗）。
2. **选方案**（三选一，不要叠加）：
   - **方案一 · 主动边界探索型（The Proactive Explorer）** —— 治"浅"。要求先摊开问题边界：已知什么、未知什么、哪些假设没验证，再给结论。适合技术选型、方案评审。
   - **方案二 · 情境化优先级型（The Contextual Prioritizer）** —— 治"散"。要求先排序：在**当前这个具体情境**下，哪一条最要紧、哪一条可以暂时不管。适合多问题并发、资源有限时的决策。
   - **方案三 · 极简优雅型（The Elegant Minimalist）** —— 治"冗"。要求砍掉一切铺垫与复述，只留结论与依据。适合结论已明确、只需要传达的场合。
3. **落地**：把选中方案的措辞写进 system prompt 或任务描述，**一次只加一套**——三套同时塞进去会互相打架，模型只会变得更啰嗦。
4. **校验**：对比注入前后同一问题的输出长度与信息密度，确认真的变好了。

## 反合理化

- "三套都写上，模型自己会选"——模型不会选，只会把三种要求揉成一锅。
- "先随便选一个试试"——选错方案比不选更糟，会放大原来的毛病。
- "回答越长越显得认真"——冗长是认知负担，不是深度。

## 验证

必须给出：① 判定属于哪一类问题；② 选中的方案及理由；③ 注入前后的对比样本（同一问题的两次输出）。
