# 商业分析

## 适用
对一个商业设想、产品方向、市场机会做结构化分析并提出可验证的下一步。
不适用: 需要专业资质出具的意见 (金融投资/法律 → 走高风险域护栏, 只做输入不做结论)。

## 流程

1. **先把问题写成一句可判断的话**: "X 业务在 Y 场景下能否在 Z 成本内盈利"。含糊的问题 ("这个方向怎么样") 没法分析, 先收敛。
2. **五要素逐个过**:
   - 客户: 具体是谁, 现在用什么替代方案, 为什么愿意换
   - 价值: 解决什么痛点, 痛到什么程度 (不用会怎样)
   - 成本: 获客 / 交付 / 维护 / 组织, 分固定与变动
   - 竞争: 现有玩家、进入门槛、我方差异化的可持续性
   - 风险: 政策、技术、需求、供应链、现金流的脆弱点
3. **每个要素写出核心假设**: "假设 X 成立则结论成立"。**假设必须可被证伪** —— 写不出证伪条件的假设是信念不是假设。
4. **排列假设的验证成本**: 最便宜且最致命的假设最先验证。分析的价值不在结论, 在于指出该先验证什么。
5. **反证条件**: 明确写"出现什么信号就说明这个方向不成立"。没有反证条件的分析会变成自我确认。
6. **规模估算必须给口径**: 自下而上 (单位经济 × 数量) 优于自上而下 (市场规模 × 份额)。给不出数据支撑写"数据不足", 不估算。
7. **输出**: 问题定义 → 五要素分析 → 核心假设清单 (含证伪方式) → 验证优先级 → 反证信号 → 待决策事项。

## 反合理化
- "市场很大所以能做" → 市场规模与你能否拿到份额是两件事。看单位经济。
- "没有竞争对手" → 没有竞争通常意味着没有需求, 或者你没找到他们。
- "先做出来再看市场反应" → 验证需求比验证实现便宜得多。先验证最贵的那个假设。
- "这个数字是估算的, 大概差不多" → 无口径的估算会成为后续所有决策的地基。宁可写"数据不足"。
- "风险部分简单提一下" → 风险是分析的主要产出之一, 不是免责声明。

## 验证
- [ ] 问题被写成了可判断的陈述
- [ ] 五要素均有内容且带依据
- [ ] 核心假设可证伪
- [ ] 假设按"验证成本 × 致命度"排序
- [ ] 有明确的反证信号
- [ ] 规模估算给了口径, 或明确写"数据不足"
- [ ] 未越界到投资/法律结论
