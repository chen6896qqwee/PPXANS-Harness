# brainstorm — 发散与收敛

## 流程

1. **复述问题**：用一句话写下真实目标与成功标准。目标写不清就先问，别急着给方案。
2. **发散（不评判）**：列出 ≥6 个方案，含"看起来不靠谱的"。此阶段禁止自我审查。
3. **归类**：把方案归到 2–4 个方向（如：最小改动 / 一步到位 / 换个思路 / 不做）。
4. **收敛**：每个方向选 1 个代表方案，按「代价 / 收益 / 可逆性」三列打分。
5. **推荐 1 个 + 备选 1 个**，说明为什么淘汰其余。

## 反合理化

- "只有一个方案"——那就是还没发散完，回去重来。
- "细节以后再想"——不可逆决策不允许以后再想。
- "先做起来看看"——先做起来的前提是能回滚。

## 验证

完成后必须给出：① 至少 6 条候选；② 打分表；③ 明确推荐项 + 淘汰理由。
