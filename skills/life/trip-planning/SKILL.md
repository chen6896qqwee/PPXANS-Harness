# 出行规划

## 适用
需要产出可直接照着走的行程安排 (旅行、出差、多地办事)。

## 流程

1. **先收硬约束** (缺一项必返工): 日期与总天数、人数与同行者情况 (老人/小孩)、预算区间、必须达成的事 (会议/景点/办事)、绝不能接受的 (转机/早起/长途步行)。
2. **定锚点再填内容**: 先固定不可移动项 (航班、会议、预约), 剩下的空档再排活动。反过来排必然冲突。
3. **按地理聚类**: 同一天的活动尽量在同一片区。跨区移动单独标出交通方式与耗时 (含高峰冗余 30%~50%)。
4. **每天留 20% 空档**。满档行程第一天就会崩, 之后全程雪崩。
5. **每项标注四要素**: 时间 / 地点 / 交通 / 需要提前准备什么 (预约、证件、购票、着装)。
6. **给备选而非只给一套**: 每个关键时段提供一个雨天/延误/堵车时的替代项。
7. **信息核验**: 营业时间、门票、预约要求、交通班次属于易变信息 —— 必须查实时来源并标注查询时间; 查不到就写"需自行确认", 不要凭记忆写。
8. **输出**: 行程总览表 (日/时段/活动/交通/准备) + 交通与住宿清单 + 备选方案 + 待确认项 + 打包清单。

## 反合理化
- "先想想去哪玩再排时间" → 时间是硬约束, 先定日期与会面, 再选活动。
- "营业时间我记得是 9 点" → 记忆里的时间会害人白跑。查一次, 或标注未核实。
- "排满一点才不浪费" → 排满等于没有容错。延误一次全天报废。
- "备选不用写, 到时候再看" → 到了当地再查最慢最贵。备选在出发前 5 分钟就能写好。
- "预算后面再算" → 预算决定住宿位置与交通方式, 这两项决定整个行程骨架。

## 验证
- [ ] 硬约束五项已确认
- [ ] 锚点 (不可移动项) 优先固定
- [ ] 同日活动按地理聚类, 跨区交通含冗余
- [ ] 每天留 ≥ 20% 空档
- [ ] 每项四要素齐全
- [ ] 关键时段有备选
- [ ] 易变信息已核验并标注查询时间
