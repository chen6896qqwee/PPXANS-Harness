# 丘比特 · 可自定义角色沟通素材库（Role-based Chatting Kit）

为拟人化角色（陪伴、客服人格、虚拟伴侣）提供分阶段的沟通素材，避免"上来就掏心窝子"这类失真人设。

## 流程

1. **定关系阶段**：先确定当前处于哪个阶段——初识 / 熟悉 / 亲近 / 稳定。阶段决定可用的亲密度和话题深度。
2. **套漏斗（The Funnel）**：话题只能逐级下探，不可跳级。初识谈事实与兴趣，熟悉谈观点与经历，亲近才谈情绪与脆弱。
3. **选话术**：同一意图准备"好话术 / 坏话术"两版对照——好话术给具体动作与承接，坏话术是套话与自我中心。
4. **补话题引子**：从话题库里按阶段取 3–5 个开放性问题，避免只能回答"是/否"的封闭问题。
5. **检查人设一致性**：把生成的回复与角色设定对齐——用词、语气、关注点是否像同一个人说的。

## 好话术 vs 坏话术（对照表）

| 场景 | 坏话术 | 好话术 |
|---|---|---|
| 对方说累了 | "那你早点休息" | "今天是什么事最耗神？说出来我陪你顺一遍" |
| 对方分享好消息 | "恭喜恭喜！" | "这个你准备了挺久吧，最得意的是哪一步？" |
| 对方情绪低落 | "别想太多了" | "先不急着解决，你想让我听着，还是想一起想办法？" |
| 自己想表达关心 | "我一直都在" | "你上次提的那件事，后来怎么样了？" |

> 判据：**坏话术结束对话，好话术开启下一步。**

## 反合理化

- "话说得越热络越像真人"——热络不等于亲密，越级热络是典型的人设崩塌。
- "套话最安全"——套话没有信息量，对方接不下去，对话就死了。
- "一句万能回复走天下"——同一个回复跨越所有阶段，等于没有阶段设计。

## 验证

必须给出：① 当前关系阶段判定；② 该阶段允许的话题深度；③ 好/坏话术对照至少 3 组；④ 人设一致性检查结果。
