## 本轮核心：四刀重构收口，内核瘦身 1238 → 955 行

皮皮虾内核从「1238 行上帝对象」拆成清晰的**内核 / 服务 / 编排**三层，全部等价重构（无功能变更，测试全绿锁定），再加首个功能增量。

### 第一刀 · 工具循环策略抽离 (`core/policy.js`)
- 探索熔断 / 重复命令检测 / 溢出降档 / 错误重试 / 轮次上限 从 `_llmWithTools` 抽成 `ToolLoopPolicy` 状态机 + `runToolLoop` 循环驱动
- 依赖全部注入，**不持有 agent 引用**，可独立测试、可替换

### 第三刀 · 结构化事件流 (`core/trace.js`)
- **AsyncLocalStorage traceId 贯穿**：一次对话的所有深层异步调用（记忆提炼/压缩/检索/自愈/spawn）自动继承同一 traceId
- 事件流写 `data/logs/traces/events-*.jsonl`，落盘前 PII 脱敏
- **安全增强**：修复 URL query 凭证未脱敏漏洞（`?token=xxx` 等参数值现落盘前替换为 [REDACTED]）

### 第二刀 · 记忆+学习服务化 (`services/`)
- `memory-service.js` 记忆协调：L1提炼/L2归档/L3画像/经验/检索 + **`afterTurn()` 升降级协调器**
- `learning-service.js` 自我学习：refine（失败→经验）/ refineSkill（成功→技能）/ upgradeSkill（使用中进化），验证闸门保留

### 第四刀 · 工具超时预算 (FEATURE)
- 工具级 `timeoutMs` 声明 + 全局默认 `agent.tool_timeout_ms=30000` 兜底
- 超时 → **幂等工具自动重试一次** → 结构化错误；非幂等不重试（副作用安全）
- **修复真 bug**：原超时只靠 AbortController signal，不配合的工具会永久挂死对话 → 新增 `Promise.race` 双层兜底，挂起工具 100ms 内强制返回
- 超时触发 `tool/timeout` trace 事件（含耗时/预算/重试状态），为熔断/自适应预算铺数据
