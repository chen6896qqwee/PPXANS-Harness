## 逐轴证据

### 写入 —— A
- `recordTurn(user, assistant, opts)`：每轮蒸馏入库；evidence/drafts 只进 turns 可重建档、**不进蒸馏**（防证据污染记忆，`memory-ticker.js` L247-258）
- provenance 声明随写随落（`source: "extract"` = 模型推断，与实测事实区分）
- L1 增量 WAL（`facts.json.wal` 追加写 + 崩溃 replay），写放大已治理（v3.2.2）
- extractor 钩子（`setExtractor`）支持 LLM 结构化提炼（memory-service）

### 遗忘 —— A-
- TTL 90 天软归档（`status=deleted`，可 restore，非硬删）+ 每日 02:00 排泄治理
- L1 高斯衰减 `decay_per_day` + 命中加分 `hit_bonus`（重要性动态化）
- 容量上限 `max_facts` + prune/tombstone purge + WAL 边界（`wal-bound` 守卫）
- 失败记忆同毫秒裁剪错杀已修（v3.2.3，ts 单调化）
- 扣分点：跨层遗忘联动（L1 归档后 L2/L3 引用是否悬挂）无自动对账

### 检索 —— B+（2026-10-09 复核修正: 初评 C+ 系审查遗漏）
- 现状（复核后确认）: `facts.query()` **已是 BM25**（IDF 区分常见/罕见词 + 长度归一 + 倒排候选集 + scope 缓存），叠加子串强信号 + 高斯衰减乘性时效 + 命中权重 + 重要性因子（CrewAI 三因子齐了）
- 另有 `queryMulti` 多查询变体 + RRF 融合、可插拔 embedder 钩子（`setEmbedder`, 零依赖默认关闭）
- 剩余缺口收窄为: **语义/换说法泛化**（embedder 默认关，接入需可选依赖或外部服务）——原"BM25 待做"撤销

### 演化 —— B-
- A-Mem 插件（2026-10-09）：卡片自动链接 + 邻居演化注记，但仅词面启发式、仅 amem 后端内
- LLM `extractMemory` 每轮蒸馏 = 内容演化雏形，但无跨轮记忆间关系维护
- L1 facts 相互独立，无链接/冲突合并（同事实多版本并存靠 dedupe 工具人工触发）
- 候选路线：A-Mem 演化机制下沉为 trait 接口的可选能力（缺口 2 第②步一起设计）

## 结论与行动
1. **最弱轴 = 检索**，确认评价时的预判。下一步先做零依赖 BM25 打分（`facts.query` 内部替换，接口不变，全量回归兜底）——列入 v3.3 候选
2. 演化轴随 trait 接口一并设计（A-Mem 已证明该形态可行）
3. 遗忘轴补一条跨层悬挂引用对账（低成本守卫）
4. 写入轴不动——已经是护城河
